# Playwright Saucedemo Tests

End-to-end UI test automation for https://www.saucedemo.com using Playwright and TypeScript.

## What is tested
- Login with a valid user
- Adding a product to the cart and verifying it appears in the cart

## Tech stack
- Playwright
- TypeScript
- Node.js
- GitHub Actions (CI)

## How to run
1. Clone the repo
2. Run `npm install`
3. Run `npx playwright install`
4. Run `npx playwright test`
5. View the report with `npx playwright show-report`
